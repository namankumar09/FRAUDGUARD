# Behavioral AI Fraud Prevention & Biometric KYC Detection Platform

A full-stack enterprise behavioral intelligence platform that detects account takeover, bot fraud, impersonation, synthetic KYC identities, and pre-transaction malicious intent.

## 🚀 Features

- **Real-Time Transaction Stream**: Live monitoring of transaction telemetry with dwell time, keystroke flight dynamics, and clipboard paste detection.
- **Precursor Intent Detector**: Detects fraudulent intentions 10–30 micro-actions before the transaction button is pressed.
- **Behavioral Onboarding Engine**: Biometric KYC scoring measuring keystroke dynamics, flight variance, and robotic automation patterns.
- **Zero-Day Anomaly Radar**: Unsupervised pattern detection uncovering novel fraud vectors.
- **DNA Mutation Tree**: Continuous comparison against calibrated customer baselines.
- **Doppelgänger Clusters**: Graph correlation of synchronized multi-account bot farms.
- **Global Light & Dark Theme**: Full contrast mode switching supporting light and dark environments.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Recharts, Motion, Canvas Confetti
- **Backend**: Node.js, Express, tsx, esbuild
- **AI Integration**: Server-side Google GenAI SDK

## 📦 Getting Started

### 1. Clone or Download the Repository
```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
The app will run at `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
npm start
```
